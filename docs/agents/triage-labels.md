# Triage Labels

工程技能使用五种标准 triage 角色；本仓库直接采用相同字符串作为本地跟踪器状态。

| 工程技能角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整说明，可由 agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施或判断 |
| `wontfix` | `wontfix` | 不再处理 |

当技能提及某个标准角色时，使用本表对应的本仓库标签。
