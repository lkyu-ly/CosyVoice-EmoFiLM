### 1.3 关键事实（来自报告，避免重复调研）

- 输入端句级 CE 是文本可分捷径：探针读回 100%、emotion_encoder 梯度与 loss_tts 反方向（cos −0.26）、WER 劣化；"可训练有锚点分类器"救不了输入端。
- 有效声学条件强度与句级监督无关；FiLM 调制方向落在语音预测器低敏感方向。
- 情感匹配 prompt（同说话人同情感不同句）可把 4 模型推到 84–87 / 5-way 73–83%——这是**上限参照**，不是正式评测口径。
- 正式主线评测**保持中性 prompt**（更严格，测模型自身能力）；双轨保留（中性=能力、匹配=上限）。
- CV3 官方基线（instruct + 中性 prompt）70.76 未质变 → 换基座不是瓶颈解；CV3 权重已本地可用，建议暂缓迁移，作为 R2/R3/R4 落地后的捆绑对照。

## 2. 修正后的方向建议

### 2.1 立即推进（最高优先级）

**R2 监督改造——把情感监督从文本嵌入 CE 移到音频/生成链下游。**

- 为什么：实验已证明模型在中性 prompt 下缺"自产情感声学差异"的能力；输入侧 CE 是捷径，声学侧从未被监督到。
- 两条候选路径（**待决策，见 §4**）：
  - 首选（文档）：emotion2vec 音频奖励 + DPO/GRPO（参照 `reference/Emo_PA_code_data/reward_tts.py`；FlexiVoice S1 配方与 ESD 同文本跨情感对同构）。
  - 备选/辅助：接通输出侧 span 词级监督（`emotion_head`/`arousal_head` 已实现未接线；IEMOCAP 5484 条词级标签已有）。
- 并行：输入 CE 默认关闭（基线配置已 0，无需改）；新训练配置新建，不动历史配置。

**R3 FiLM 数值修复——工程最便宜、立刻降 WER，可与 R2 并行/前置。**

- 具体：`EmotionEncoder` embedding 归一化（LayerNorm 或固定缩放）；`FiLMLayer` γ/β 幅度约束（tanh 限幅或 1/sqrt(dim) 缩放）；目标调制幅度 ≤0.2–0.5× text 范数。
- 验证：5-epoch 小跑 + WER/modulation ratio（`/tmp/emofilm_mod_analysis.py` 可复测）。

### 2.2 作为 R2 的配套（按文档优先级）

**R4 条件注入结构改造**（高优先级，文档列为 R2 之后）：词级 FiLM / speech-token 侧注入 / learned emotion tokens 三选一（可组合）。**待决策**（§4）：是否与 R2 捆绑，选哪种形态。

**R5 骨干 LoRA/部分解冻**（中优先级）：文档明确"配合音频奖励一起训"——即 R5 应捆绑在 R2 首选路径（RL/奖励）上，不单独做。

**R6 早停/选点情感感知**（中优先级）：依赖"判别指标增强"（§3 前置项 1）提供情感感知 CV 指标；`EarlyStopTracker` 扩展 metric + aux_metric。

**R7 LR/时长/数据**（低优先级）：协议与监督修正前不加预算；R2 落地后再调整 LR 策略与数据扩展。

### 2.3 暂缓/搁置

- **CV3 迁移**：结论已定（基座非瓶颈），搁置为 R2/R3/R4 落地后的捆绑对照实验；本地权重保留。
- **R4 的 Flow 侧情感条件**（报告 R1 可选项）：属于生成协议结构改造，工作量大，先于 R2 判断是否必要（若 R2 后中性 prompt 能力明显提升则不必）。

## 3. 调整算法前必须做的事（实现角度，前置项）

1. **判别指标增强**：`compute_discriminability` 合并 eval manifest 的 `reference_wav`（自身情感参考）与 sources 索引（其他情感参考），使主线 eval 集判别恢复可用（n-way、n_skipped 如实报告）。这是 R6 的前提，也让正式评测具备情感区分度维度。
2. **v3 全量中性基线**：跑 `exp/emofilm_{v1,film_only,film_only_longepoch,sentlvl}/run_eval.sh`，产出四模型 3 数据集全量的 `eval/v3/*_metrics.json`（含 per-emotion）；作为后续任何训练改进的同口径对照组。
3. **v1 legacy padded ckpt 规范化**（小决策）：给 `load_emofilm_model` 加显式 legacy 模式，或保留 padded 文件并在合同注明来源；二选一即可，不阻塞主线。
4. **评测双轨口径确认**：中性 prompt = 正式能力评测；情感匹配 prompt = 上限诊断。两者都在评测体系内保留，不互相替代（已在 §1.3 定论）。
